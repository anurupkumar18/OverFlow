---
title: Data and evidence provenance
type: check
when: PR changes catalog, evaluation, telemetry, documentation claims or public configuration
actions: Report fabricated evidence, lost provenance or secret exposure
---

Only the normalized catalog belongs in app/data; retain official-source provenance, UTC intervals and room-clash validation. Treat uniform capacity as estimated. Keep human and agent actions distinct. Provider findings, PR counts, video links and remote telemetry require real artifacts. Dedicated browser ingest tokens are the only intentionally public credential; never expose server credentials, raw search terms or attendee IDs in telemetry.
