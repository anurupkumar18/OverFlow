# Product facts

Overflow is one stateless Node service with Elasticsearch as its only server datastore. The checked-in public schedule is read-only fallback; private browser saves do not count as crowd interest. No LLM is in the request path.

UTC timestamps end in Z; display and day filters use America/Denver. Plan B has at most three different-room talks starting within ten minutes, not ended and not known full. Same-floor preference requires the same venue. Live ranked results retain provider relevance within that preference.

Unknown counts are null. Capacity200 is an explicitly labeled planning estimate. Pressure is bookmarks/capacity, with likely-full at pressure>=1 or two distinct recent full reports. Smoke identities never affect actual crowd counts. Partial provider results are unavailable, not zero or all-clear.

Search and Plan B disclose the mode actually executed and any degradation. A mode change during pagination restarts at offset zero and pins that result set's mode ceiling.

Only dedicated ingest-only browser telemetry credentials may be public. Server ES/admin/Dash0 read/OTLP credentials never appear in browser output or logs. No remote deployment, human labels, provider findings or review counts may be invented.
