# Build lessons

1. Check actual attachment paths before planning around their contents. The named plan and palette were absent; two pasted reference documents remained available. Ask for optional missing visual direction while building independent work.
2. Use primary schedule data and inspect time semantics. Sessionize timestamps lack offsets; the official page specifies MST (UTC−7). The catalog also contains simultaneous posters that must not be treated as single-room talk clashes.
3. Exercise complete telemetry export. Installing a current Node SDK beside the legacy logs API silently lost logs. A bounded local collector check caught it; using the current stable logs API exported all three signals.
4. Keep physical locations in matching logic. Identical floor names across different buildings do not imply a short same-floor walk.
5. Treat HTTP 200 as transport success, not complete evidence. Elasticsearch timeouts, failed shards and truncated aggregation/search results must never become live zero counts or an all-clear.

6. Audit the full brief after a polished local milestone. Missing hybrid Plan B, RUM and release checks were implementation gaps, not cloud-access blockers.
7. Test telemetry at a collector boundary. Stable `url.query` leaked a synthetic search/page input despite legacy URL redaction; combined browser/server export exposed it.
8. Preserve verified safety evidence through fallback. Losing the known-full set while switching ranking modes can undo a correct earlier crowd check.
9. Evaluate the proposed corpus. Fresh requests against an old index cannot validate a changed checked-out catalog.
10. Evaluation compares the same experiment. A baseline needs the same query cohort, judgments, corpus and ranking configuration; measured scores across different cohorts are not a regression check.
11. Persist personal choices, not current observations. Crowd state must be refreshed or become unknown after reload; cross-tab controls must reflect the latest personal choice.
12. A pagination cursor belongs to an ordering. Reset when fallback changes ranking, and preserve that mode for subsequent pages so no sessions are silently skipped.
13. Real retrieval can expose coverage gaps that query-shape fixtures miss. Test representative catalog sessions against an actual index, and distinguish broader candidate coverage from human-judged relevance.
14. Polling must preserve keyboard focus. Update changing signal elements in place instead of rebuilding an otherwise unchanged personal-plan list.
