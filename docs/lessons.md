# Build lessons

1. Check actual attachment paths before planning around their contents. The named plan and palette were absent; two pasted reference documents remained available. Ask for optional missing visual direction while building independent work.
2. Use primary schedule data and inspect time semantics. Sessionize timestamps lack offsets; the official page specifies MST (UTC−7). The catalog also contains simultaneous posters that must not be treated as single-room talk clashes.
3. Exercise complete telemetry export. Installing a current Node SDK beside the legacy logs API silently lost logs. A bounded local collector check caught it; using the current stable logs API exported all three signals.
4. Keep physical locations in matching logic. Identical floor names across different buildings do not imply a short same-floor walk.
5. Treat HTTP 200 as transport success, not complete evidence. Elasticsearch timeouts, failed shards and truncated aggregation/search results must never become live zero counts or an all-clear.
6. Evaluation compares the same experiment. A baseline needs the same query cohort, judgments, corpus and ranking configuration; measured scores across different cohorts are not a regression check.
7. Persist personal choices, not current observations. Crowd state must be refreshed or become unknown after reload; cross-tab controls must reflect the latest personal choice.
8. A pagination cursor belongs to an ordering. Reset when fallback changes ranking, and preserve that mode for subsequent pages so no sessions are silently skipped.
